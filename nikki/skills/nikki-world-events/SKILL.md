# Nikki World Events

Prefer central banks, governments, exchanges, regulators, EIA, OPEC, and company filings. Aggregator headlines are discovery leads only.

For each event return title, occurred_at, published_at, source_name, source_url, affected_assets, mechanism, and evidence_status. Use verified, partial, or unverified. Return at most eight events. Never turn headline direction directly into price direction.
