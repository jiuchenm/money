# 潮 Tide

这套知识库是给我自己用的决策工具。目标只有一个：看清一个大机会正处在周期的哪一段，在合适的时点上车，跟着拿到它结束。

名字叫「潮」，因为潮水有涨有落，涨完必退。这正是散户最容易忘的一点——大家只惦记着涨。李小龙说 be water，讲的也是这个：不预设、不执念，跟着周期的形状走，该进则进，该退则退。

它不是一个只往里放东西的资料库。它要能转起来，帮我做判断：

```
读懂历史规律 → 采集当下信号 → 推演接下来会发生什么 → 事后回头复盘 → 修正规律
```

复盘的结论会反过来改进前面的规律。转一圈又一圈，经验就沉淀下来了。

## 两个要分开想的问题

买对一个方向不够，还得买对里面的公司。这是两个独立的问题：

- **什么时候买、什么时候卖**——看[怎么分清浪潮是哪一类](/framework/taxonomy)。
- **买这个方向里的哪家公司**——看[怎么选对公司](/selection/capability)。买有壁垒的，别买蹭概念的。

两个都做对才赚得到大钱。方向对了买错公司，或者公司对了买在错的时点，都会亏。

## 内容分四层

| 层 | 放什么 | 多久更新一次 |
|---|---|---|
| 不变层 | [方法论](/framework/taxonomy)、[选股](/selection/capability) | 一个季度改一次 |
| 研究层 | [产业研究](/industry)、技术路线和价值链 | 产业结构发生变化时 |
| 慢变层 | [宏观资产与具体标的 Track](/track)、[在跟踪的浪潮](/waves/template) | 有关键数据时 |
| 快变层 | [定期分析日志](/blog) | 每周或每月 |

## 建议的阅读顺序

1. 先读[怎么分清浪潮是哪一类](/framework/taxonomy)，建立看问题的框架。
2. 进入[产业研究](/industry)，看增长来自哪里，价值会落在哪些环节。
3. 再读[怎么选对公司](/selection/capability)，学会挑标的。
4. 查看[Track](/track)，看宏观环境和经营数据有没有支持当前判断。
5. 最后看[分析日志](/blog)，了解最近发生了什么。

写这些文章遵守一份[写作约定](/reference/writing-style)，为的是自己以后读起来快、用得上。
