# 用付费和任务成功率验证浪潮

更新于 2026 年 7 月 27 日。

> 判断 AI 办公是否进入主升，不看发布了多少 Agent。看企业是否持续使用、愿意付费，并逐步把真实业务动作交给它。

## 先定义一项真实任务

一项完整任务至少包含：

1. 读取正确的数据；
2. 遵守用户和组织权限；
3. 调用一个或多个工具；
4. 生成可检查的结果；
5. 记录引用、动作和责任人；
6. 出错时可以停止、撤销或交给人工。

只生成一段文本不算完成企业任务。

## 跟踪使用是否持续

| 指标 | 为什么重要 |
|---|---|
| AI 周活席位 | 排除开通后不用 |
| 4 周、12 周留存 | 判断是否形成工作习惯 |
| 每周完成任务数 | 比问答次数更接近价值 |
| 活跃企业占付费企业比例 | 判断部署是否扩散 |
| 部门覆盖率 | 判断是否从个人试用进入组织 |
| 关闭或禁用 AI 的企业比例 | 暴露信任和治理问题 |

累计用户、累计组织和累计 Token 都不能替代留存。

## 跟踪 Agent 是否真的能办事

| 指标 | 进入加速期需要看到什么 |
|---|---|
| 端到端任务成功率 | 持续提高 |
| 人工接管率 | 持续下降 |
| 撤销和回滚率 | 下降且原因可定位 |
| 权限拒绝率 | 合理下降，不靠放宽权限 |
| 错误动作率 | 保持极低 |
| 平均完成时间 | 明显低于人工 |
| 跨应用动作数 | 增长但不增加错误 |
| 引用和证据覆盖率 | 提高 |

Agent 能调用十个工具不代表它能完成任务。工具越多，错误传播链越长。

## 跟踪企业是否愿意付费

| 指标 | 强信号 |
|---|---|
| AI 增购率 | 已有客户主动购买 AI 权益 |
| 续费率 | AI 套餐到期后继续保留 |
| 净收入留存 NRR | 客户扩席和增购大于流失 |
| 人均 AI 收入 | 随使用深度提高 |
| 试点转全员比例 | 部门试用能扩大 |
| 客户回收期 | 实施和获客成本可以收回 |
| 经常性收入占比 | 软件收入不依赖一次性项目 |

签约、共创和案例公告不等于续费。

## 算清每项任务的单位经济

```
单任务贡献
= 单任务收入
- 模型推理
- 检索、存储和网络
- 第三方工具调用
- 人工审核和客服
- 失败任务与赔付
```

模型价格下降有利于平台。客户价格也会下降，竞争者还会把 AI 塞进基础套餐。

平台要证明：

1. 使用量增长没有让服务成本失控；
2. 推理成本下降快于售价；
3. 实施和定制不会吞掉软件毛利；
4. Agent 减少的人力成本高于订阅和治理成本。

## 看企业把多少关键数据交给平台

| 数据或动作 | 价值 | 风险 |
|---|---|---|
| 文档和知识库 | 提高回答质量 | 敏感信息泄露 |
| 群聊和会议 | 补充实时上下文 | 员工监控和隐私 |
| 客户沟通 | 接近收入和服务 | 消费者知情和骚扰 |
| 业务表格 | 支持分析和自动化 | 数据口径混乱 |
| 审批和财务动作 | 可以真正执行 | 误操作损失高 |
| 外部系统凭证 | 跨系统完成任务 | 凭证泄露和权限升级 |

企业愿意开放的权限深度，比模型榜单更能说明产品成熟度。

## 识别五种假繁荣

### Token 增长

Token 增长可能来自重复生成、低效提示和免费额度。它不自动产生收入。

### Agent 数量增长

模板和机器人很容易创建。长期周活和生产调用更重要。

### 累计组织增长

注册企业、共创企业和付费活跃企业是三种口径。

### 大客户签约

合作公告不等于全员部署。要看试点范围、扩席、续费和合同回款。

### 录音硬件增长

硬件可以增加会议和面聊数据。它也可能只是低毛利入口，不能证明 SaaS 收入。

## 什么时候上调阶段

AI 办公进入主升阶段，需要同时看到：

1. 多个平台披露 AI 活跃和 12 周留存；
2. 真实企业从部门试点扩大到集团部署；
3. Agent 可以稳定完成跨应用任务；
4. AI 增购、续费和净收入留存提高；
5. 单任务成本下降；
6. 权限和安全事故没有随使用量同步上升。

当前只满足产品供给和部分使用扩散。商业证据还不完整。

## 什么情况说明浪潮没有兑现

- Agent 长期停留在搜索、总结和写作；
- 企业只允许读取，不允许执行；
- AI 使用增加但付费和续费不升；
- 错误动作和人工接管长期过高；
- 模型成本下降后，AI 被免费打包，平台无法增收；
- 大型客户需要大量定制，无法复制交付；
- 数据泄露、骚扰或监管事件迫使平台关闭核心能力；
- 操作系统或基础模型掌握入口，办公平台被压成低价工具。
