# 先看 AI 如何进入真实工作

更新于 2026 年 7 月 27 日。

> 当前结论：AI 办公已经越过写作和摘要阶段，开始进入企业知识、权限和工作流。搜索与总结处在加速扩散期，能够跨系统执行任务的 Agent 仍在商业验证期。

## 四家公司争的不是同一个入口

| 平台 | 已经占住的位置 | 最难复制的资产 | 当前最需要证明什么 |
|---|---|---|---|
| 钉钉 | 组织、审批和内部工作流 | 通讯录、权限、流程、宜搭和开放生态 | Agent 能稳定执行，并带来续费和增购 |
| 企业微信 | 员工与微信客户的连接 | 微信关系链、客户群、离职继承和客户经营 | AI 能进入客户场景，同时守住消费者合规 |
| 飞书 | 文档协作和结构化业务 | 文档、多维表格、组织权限和协作上下文 | Agent 增购能提高续费和净收入留存 |
| WPS | 文档编辑和最终交付 | Office 内核、格式兼容、桌面端、离线和信创 | AI 使用能转成个人 ARPU 和企业订阅收入 |

这四种资产可以同时存在于一家企业。

员工可能用企业微信服务客户，用飞书管理项目，用 WPS 处理正式文件，再通过钉钉完成审批。AI 会推动平台整合，也可能让这种组合长期存在。

## 把 AI 办公拆成六层

| 层 | 负责什么 | 能不能形成壁垒 |
|---|---|---|
| 基础模型 | 理解、生成、推理 | 模型快速迭代，独占性正在下降 |
| 企业上下文 | 消息、文档、会议、客户和业务数据 | 数据沉淀越深，迁移越难 |
| 身份与权限 | 谁能看、谁能改、谁能批准 | 企业 Agent 的必要基础 |
| 工具与工作流 | 创建文档、更新表格、发消息、审批和调用系统 | 从回答问题走向完成任务 |
| 审计与回滚 | 引用、日志、授权、撤销和人工接管 | 决定大型企业敢不敢放权 |
| 用户入口 | IM、Office、微信客户、操作系统和硬件 | 决定谁掌握分发和收费权 |

基础模型变好会抬高所有平台。真正的能力租金来自后五层。

## 行业现在走到哪一步

### 搜索、总结和内容生成已经扩散

四家都已经提供文档问答、会议总结、写作和表格分析。产品差异正在缩小。

这部分能节省时间，但容易被模型和竞品复制。企业是否愿意单独付费仍取决于使用频率和套餐设计。

### 企业知识问答开始形成使用习惯

模型按原有权限搜索聊天、文档、会议和邮件，价值高于开放互联网问答。

接下来要看答案引用率、纠错率、权限命中和持续周活。开通知识库不等于员工真的使用。

### Agent 执行处在验证向扩散过渡

2026 年以来，四家都在开放 CLI、MCP、插件或 Agent 平台：

- 钉钉发布悟空和 DingTalk Workspace CLI；
- 企业微信开放长连接、MCP 和 CLI；
- 飞书强化 aily、多维表格 Agent、妙搭和 CLI；
- WPS 推进灵犀、Comate 和 Office Agent。

这些产品已经能调用部分工具。端到端成功率、人工接管率、回滚能力和生产客户数量仍缺少公开数据。

### 自主经营客户仍在萌芽期

企业微信最接近客户场景，但官方机器人暂时不能直接进入外部客户群。其他平台也没有证明 Agent 可以在缺少人工监督时持续处理销售、采购或财务事务。

现在更准确的说法是“AI 帮员工工作”，还不是“AI 独立接管岗位”。

发布频率已经很高。市场仍缺少统一、可复核的 Agent 付费率和生产任务成功率。

## 分清能力租金和身位红利

### 钉钉的能力租金

组织通讯录、审批、宜搭应用和第三方系统已经嵌入企业。Agent 可以在这些权限和流程内执行。

管理层更换和产品重组属于短板。若接口和产品名称持续变化，迁移成本也会变成客户的不安全感。

### 企业微信的能力租金

微信消费者不需要安装新应用，就能与企业员工建立关系。客户归属、群聊、朋友圈和离职继承很难被其他办公软件复制。

这项能力也带来隐私、骚扰和消费者知情风险。自动化越深入，监管约束越强。

### 飞书的能力租金

文档记录非结构化知识，多维表格保存结构化业务，IM 和会议提供实时上下文。Agent 可以在同一权限体系中读取和执行。

低代码应用大量增长后，也可能形成数据口径混乱和无人维护的影子 IT。

### WPS 的能力租金

AI 最终要交付可编辑的文字、表格、演示和 PDF。复杂格式、公式、打印、桌面端、离线和国产系统适配需要长期工程积累。

如果自然语言入口被其他平台掌握，WPS 可能只剩后台文档引擎。灵犀和 Comate 能不能建立前台入口，是下一阶段关键。

### 共同的身位红利

- 宣布接入最新模型；
- 上架大量 Agent 模板；
- 发布录音硬件；
- 披露累计组织数或累计调用量；
- 用 Token 增长代替收入和留存。

这些信号能制造关注，不能单独证明商业模式。

## 谁最接近商业化验证

WPS 是四家中财务证据最清楚的一家。金山办公单独上市，能够看到 WPS 365、个人业务、研发投入和现金流。

钉钉、企业微信和飞书都没有经过审计的独立完整财务数据：

- 阿里财报没有单列钉钉收入、利润和 AI 付费；
- 腾讯没有单列企业微信收入、员工 MAU 和付费企业；
- 飞书收入和 ARR 主要来自管理层或媒体口径，字节没有公开审计财报。

财务透明不代表 WPS 一定领先。它只意味着判断依据更可靠。

## 不要把小米当成 WPS 的母公司

金山办公由 WPS 香港直接控股，金山软件间接控股，雷军是实际控制人。小米是另一家独立上市公司。

小米与 WPS 有手机、平板、PC 和海外推广合作。两家公司共享关键人物和生态关系，不存在“小米办公事业部”或“小米母公司控股 WPS”的关系。

因此，持有小米不等于直接持有金山办公。

## 资本市场怎样映射

| 平台 | 主要主体 | 映射特点 |
|---|---|---|
| 钉钉 | 阿里巴巴 | 价值需要通过云收入、企业服务和集团协同体现，钉钉本身未单列 |
| 企业微信 | 腾讯 | 更接近微信生态和企业服务入口，收入影响被集团规模稀释 |
| 飞书 | 字节跳动 | 非上市，国内公开市场没有直接标的 |
| WPS | 金山办公、金山软件 | 金山办公是最直接的 AI 办公收入映射 |
| 小米协同 | 小米集团 | 目前主要是终端适配和渠道合作，不是 WPS 股权映射 |
