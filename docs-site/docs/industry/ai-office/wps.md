# 看 WPS 怎样守住文档交付入口

更新于 2026 年 7 月 27 日。

> 当前结论：WPS 已经从 Office 软件进入 Agent 商业化早期。它的壁垒是文档内核、桌面端、离线、格式兼容和信创交付。自然语言入口能否留在 WPS 内部，决定它收取平台租金还是只做其他 Agent 的后台工具。

## 先把金山和小米的关系说清楚

📗 截至 2025 年末：

- WPS 香港持有金山办公约 51.47%，是直接控股股东；
- 金山软件是间接控股股东；
- 雷军是金山办公实际控制人；
- 小米集团是另一家独立上市公司。

雷军同时担任金山软件董事长、金山办公董事及名誉董事长，也是小米集团董事长兼 CEO。

这形成共同关键人物和关联方关系，但不形成“小米母公司控股 WPS”。

WPS 不属于小米办公事业部，也没有并入小米财报。

## 两年内完成三次产品升级

| 时间 | 变化 | 当前判断 |
|---|---|---|
| 2024-04 | WPS 365 发布 | Office、协作和企业 AI 合并成一套产品 |
| 2025-07 | WPS AI 3.0、WPS 灵犀亮相 | AI 开始直接生成可编辑文档、表格和演示 |
| 2026-02 | 灵犀接入 GLM-5 | 继续采用多模型路线 |
| 2026-03 | 文档、表格、演示智能体升级 | 从问答走向多步 Office 操作 |
| 2026-03 | 公司提出推进 WPS AI 4.0 | 属于研发目标，不等于 4.0 已正式发布 |
| 2026-06 | WPS 笔记发布 | 补充个人知识采集和复用 |
| 2026-07 | 灵犀专业版和 WPS Comate 发布 | 个人 Agent 和企业 Agent 继续分层 |
| 2026-07 | 灵犀 Claw 邀请制内测 | 尚未全面商用 |

WPS 的 AI 路线已经从写作、摘要和公式，转向直接调用 Office 引擎完成任务。

## 文档内核为什么重要

模型生成一段文字不难。交付一份可继续编辑、计算、打印和审阅的文件更难。

WPS 长期积累在：

- Word、Excel、PowerPoint 和 PDF 格式兼容；
- 公式、图表、宏、版式和打印；
- Windows、macOS、Linux、Android、iOS 和国产系统；
- 桌面端重度编辑和本地文件；
- 弱网、离线、私有化和涉密环境；
- 国产 CPU、操作系统和政务终端；
- 公文、审批、外发权限和审计。

AI 负责理解意图。Office 内核决定结果能不能交付。

## 当前产品分成四层

### Office 和文件

WPS 文字、表格、演示和 PDF 仍是核心。金山文档提供多人协作、自动保存和权限。

### WPS 365

企业可以使用 Office、云文档、即时通信、会议、邮件、组织架构和统一管理。

WPS 已经补齐协同套件，但组织审批、客户关系和应用生态仍弱于钉钉、企微和飞书。

### 个人 AI

传统 WPS AI 负责写作、阅读、数据分析和演示设计。灵犀进一步编排多步任务，并调用 Office 引擎生成可编辑结果。

WPS 笔记把语音、图文和个人资料转成可检索知识，再复用到文档。

### 企业 AI

| 产品 | 负责什么 |
|---|---|
| AI Hub | 接入模型、控制额度和审计调用 |
| AI Docs | 企业知识库、问答和创作 |
| Copilot Pro、WPS Comate | 调用 WPS 365 和企业 API 完成任务 |
| KAG | 理解办公文档中的段落、表格、版式和权限 |
| 数字员工、企业搜索 | 扩展到考勤、业务数据和信息汇总 |

企业可以使用公有云、私有化或混合云。具体模型、算力和价格取决于合同。

## 财务证据比其他三家清楚

📗 金山办公 2025 年：

| 指标 | 数值 | 同比 |
|---|---:|---:|
| 营收 | 59.29 亿元 | +15.78% |
| 归母净利润 | 18.36 亿元 | +11.63% |
| 扣非净利润 | 18.03 亿元 | +15.82% |
| 经营现金流净额 | 25.02 亿元 | +13.93% |
| 研发投入 | 20.95 亿元 | +23.57% |

收入结构：

| 业务 | 收入 | 同比 | 毛利率 |
|---|---:|---:|---:|
| 个人业务 | 36.26 亿元 | +10.42% | 80.96% |
| WPS 365 | 7.20 亿元 | +64.93% | 91.49% |
| WPS 软件 | 14.61 亿元 | +15.24% | 95.02% |

WPS 365 是增长最快的业务。它包含企业一体化办公和 AI，不能把全部增长归因于 AI。

运营数据：

- 全球月活设备 6.78 亿；
- PC 月活设备 3.29 亿；
- 国内年度累计付费个人用户 4,615 万；
- 海外付费个人用户 285 万。

月活按设备统计，年度累计付费也不是期末订阅人数。不能直接相除计算付费率。

## 2026 年一季度利润不能外推

📗 2026Q1 营收 16.13 亿元，同比增长 23.95%。研发投入 5.72 亿元，占收入约 35.43%。

归母净利润和扣非净利润均超过 21 亿元，主要受到部分基金投资收益影响。

这不是主营办公软件和 AI 利润突然超过全年水平。判断经营趋势要继续看收入、合同负债、经营现金流和后续季度。

## AI 使用已经成立，利润池还没证明

📙 公司披露 2025 年国内 WPS AI 月活超过 8,013 万，日均 Token 超过 2,000 亿。

这能证明使用需求，不能证明收入和利润。

公司还没有单列：

- AI 收入；
- AI ARPU；
- Agent 付费席位；
- 推理成本；
- AI 续费率；
- Agent 任务成功率。

当前可以观察个人业务增长、WPS 365 增长和 AI 使用量。三者之间的因果关系仍需更多披露。

## 企业价格已经较透明

截至 2026 年 7 月 27 日，WPS 365 官方价格页显示：

| 版本 | 价格 |
|---|---:|
| 体验版 | 免费 |
| 商业协作版 | 199 元/人/年 |
| 商业高级版 | 399 元/人/年 |
| 商业旗舰版 | 599 元/人/年 |

大型企业、私有化、政务、信创、本地模型和实施服务通常按合同询价。

个人会员价格会随账户、渠道和活动变化，不适合引用一次促销作为长期标准价。

## 小米协同已经落地到终端

可以确认的合作包括：

- WPS AI 与小米手机、PC 的适配；
- 小米平板提供 PC 级 WPS 体验；
- 双方存在技术服务和海外安卓版推广合作。

小米拥有 HyperOS、手机、平板、PC 和超级小爱。理论上可以把系统级自然语言请求交给 WPS Agent 执行。

📕 截至研究日，没有充分官方证据证明超级小爱已全面调用 WPS 企业知识、灵犀或文档权限体系。系统入口协同仍是可能方向，不是已经完成的整合。

## WPS 可能失去前台入口

用户可以从钉钉、企微、飞书或操作系统 Agent 发出任务，再调用 WPS 生成文件。

这种情况下：

- WPS 保留文档执行能力；
- 入口平台掌握用户、分发和价格；
- WPS 可能被压成后台 Office Skill。

灵犀、Comate、WPS 笔记和企业搜索的任务，是让用户直接从 WPS 发起工作。

## 给当前阶段下定义

金山办公处在：

> **产品验证完成，企业订阅和 Agent 商业放量早期，独立 AI 利润模型尚未成熟。**

四家公司中，WPS 最接近用财报验证 AI 办公。它仍需证明 WPS 365 高增长可以持续，并且 AI 能提高付费、ARPU 和续费。

## 持续跟踪

| 指标 | 强信号 | 弱信号 |
|---|---|---|
| 个人端 | AI 用户转付费、ARPU 和续费提高 | Token 继续增长 |
| 企业端 | WPS 365 续费和扩席提高 | 单年收入高增长 |
| Agent | 任务完成率提高、人工修改下降 | 发布更多 Agent |
| 成本 | 单任务成本下降快于售价 | 推理成本侵蚀毛利 |
| 客户 | 民营和海外客户增加 | 主要依赖信创采购 |
| 入口 | 灵犀和 Comate 形成独立活跃 | 只被其他平台调用 |
