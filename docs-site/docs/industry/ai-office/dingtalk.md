# 判断钉钉能否变成企业 Agent 平台

更新于 2026 年 7 月 27 日。

> 当前结论：钉钉已经具备组织身份、权限、知识和流程执行的主要组件。产品方向成立，经营验证还不充分。2026 年再次换帅增加了路线连续性风险。

## 看清两年的路线变化

| 时间 | 变化 | 说明 |
|---|---|---|
| 2024-01 | 钉钉 7.5 发布 AI 助理 | 从通用生成进入可配置企业助手 |
| 2024-06 | 7.6 邀测 AI 搜索 | 开始跨企业内容检索 |
| 2025-04 | 陈航重新出任 CEO | 产品体验、中小企业和 AI 重构重新成为重点 |
| 2025-08 | 钉钉 8.0、AI 钉钉 1.0 | 推出 ONE、AI 搜问、AI 表格和 AI 听记 |
| 2025-12 | AI 钉钉 1.1 | 提出 Agent OS |
| 2026-03 | AI 钉钉 2.0、悟空 | 转向企业级 Agent 工作平台 |
| 2026-03 | Workspace CLI 开放 | Agent 可以调用表格、日历、群聊和审批 |
| 2026-06 | 陈航卸任，陈宇森接任 | 悟空与阿里内部 Agent 团队开始整合 |

📗 钉钉 Workspace CLI 已有官方文档和开源仓库。仓库仍标注“共创阶段”，不能描述成全量企业已经采用的成熟基础设施。

📙 2026 年 7 月媒体报道悟空、MuleRun 等团队可能继续整合。阿里尚未发布完整统一的产品和定价说明，这部分仍属于组织规划。

## 区分正式产品和发布会架构

| 能力 | 当前状态 |
|---|---|
| 群聊、日历、审批、待办和机器人 | 成熟商用 |
| 文档、知识库和云盘 | 正式商用 |
| AI 搜问、AI 表格、AI 听记 | 已正式发布 |
| AI 助理和助理市场 | 已正式发布 |
| 宜搭低代码 | 成熟商业产品 |
| 开放平台和第三方应用 | 成熟运营 |
| Workspace CLI | 已开源，仍在共创 |
| Agent OS | 产品架构和平台主张，独立商业数据不足 |
| 悟空 | 已发布，广泛 GA 和生产客户数据不足 |
| DingTalk Real | 已展示，规模部署状态未核实 |

钉钉已经不缺 AI 功能。缺的是第三方 Agent 的持续生产调用、任务成功率和企业付费。

## 真正有价值的是四类资产

### 组织上下文

通讯录、部门、角色和管理员定义了企业内部关系。Agent 可以知道谁负责、谁批准、谁可以访问。

### 工作数据

消息、会议、文档、表格、日历和知识库提供任务背景。

### 流程执行

审批、机器人、宜搭和开放 API 让 AI 可以更新记录、发起流程和通知人员。

### 高频入口

员工每天在群聊、待办、会议和移动通知中工作。新 Agent 不需要重新争夺一次入口。

这些资产比通义模型本身更难复制。模型可以替换，企业已经搭好的权限和流程不能轻易搬走。

## 阿里生态能提供什么

阿里云提供模型推理、计算、存储、安全和专有部署。通义千问提供主要模型能力。钉钉负责企业身份、协同和应用分发。

合理的价值传导是：

```
钉钉获得企业 AI 使用
→ 增加协同和 AI 订阅
→ 带动模型、计算和数据服务
→ 阿里云获得资源收入
```

这条链还没有被财报单独证明。

淘宝、支付宝和高德可以在商家运营、支付和本地生活场景协同。没有证据表明这些消费者和交易数据会默认向钉钉开放。跨业务数据仍需要明确授权。

## 商业化证据仍然不够

钉钉采用免费基础协同、企业订阅、专属部署、宜搭、AI 增值和生态应用的组合模式。

公开价目并不完整：

- 专业版、专属版和行业方案通常按企业规模或项目报价；
- 宜搭有独立版本和定价；
- 模型、存储和云资源可能由阿里云另行计费；
- AI 产品没有一张适用于所有客户的统一公开价目。

📙 管理层曾披露 2024 年部分期间 ARR 超过 2 亿美元。这不是阿里审计报表中的独立钉钉收入。

📙 官方应用商店自述覆盖超过 7 亿用户和 2,600 万组织。该数字接近累计注册或覆盖口径，不等于 DAU、活跃组织和付费席位。

阿里 FY2026 年报没有单列钉钉收入、利润、DAU、AI 收入和付费企业。

## 为什么客户不容易迁走

迁移需要同时处理：

- 组织通讯录；
- 群聊和历史消息；
- 文档和权限；
- 审批、考勤和人事流程；
- 机器人和第三方应用；
- 宜搭数据和自动化；
- 会议记录和员工习惯。

流程越深，迁移越难。

这项锁定也可能反噬。收费、权限和路线变化若让客户失去信任，企业会选择一次性搬走整套系统。

## 当前最大的风险是战略连续性

2025 年陈航回归，2026 年 6 月再次卸任。ONE、Agent OS、悟空、MuleRun和其他团队连续重组。

阿里继续投入企业 Agent，方向没有退出。客户仍需要观察：

- 产品名称和 API 能否稳定；
- 悟空与钉钉原有产品怎样合并；
- 中小企业与大客户定制怎样平衡；
- 过去拆除的付费墙会不会再次变化。

## 给当前阶段下定义

钉钉处在：

> **原有协同平台成熟，企业 Agent 二次验证向扩散过渡。**

进入下一阶段需要同时出现：

1. AI 功能的 12 周留存持续提高；
2. 企业愿意为 AI 增购并在续费时保留；
3. Agent 可以跨系统完成任务；
4. 人工接管和撤销率下降；
5. 组织与产品至少连续两个季度保持稳定。

## 持续跟踪

| 指标 | 强信号 | 弱信号 |
|---|---|---|
| AI 使用 | 周活和 12 周留存提高 | 只披露累计开通 |
| Agent | 生产任务成功率提高 | 只展示 Demo |
| 生态 | 第三方 Agent 持续调用 | 助理模板数量增长 |
| 商业化 | AI 增购和续费提高 | 云调用增加但钉钉无法收费 |
| 组织 | API 和产品稳定 | 再次更名、合并或换帅 |
| 客户 | 净迁入和扩席 | 单个签约案例 |
