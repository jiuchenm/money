# 用真实部署验证商业化

> 判断行业是否进入加速期，不看发布会动作。看客户是否愿意扩大付费部署，以及机器人能否稳定完成工作。

## 先看真实需求

| 信号 | 为什么重要 |
|---|---|
| 付费交付量 | 排除展示、借用和试点设备 |
| 试点转正式采购比例 | 证明客户看到了经济价值 |
| 单个客户从 5 台扩大到 50 台、500 台 | 证明机器人可以复制部署 |
| 复购订单占比 | 比新客户签约更接近真实需求 |
| 客户是否取消原有自动化方案 | 证明人形机器人有替代能力 |

下线量、规划产能、意向订单和付费在役量是四个不同数字。只有最后一个能形成持续的零部件需求。

## 计算机器人小时经济性

每次部署都要回答：

1. 每台机器人每天实际工作多少小时；
2. 每小时完成多少有效任务；
3. 每 100 小时需要多少次人工接管；
4. 可用率和 MTBF 是多少；
5. 故障后平均多久恢复；
6. 每年维护费用占售价多少；
7. 五年总拥有成本是否低于人工、机械臂或 AMR。

如果机器人仍然需要高频远程接管，它只是把现场人工换成了远程人工。

## 检查整机制造质量

| 指标 | 进入加速期需要看到什么 |
|---|---|
| 单台装配工时 | 持续下降 |
| 一次通过率 | 提高并稳定 |
| 返修率 | 随出货增加而下降 |
| 质保准备 | 没有快于收入增长 |
| CNC 零件占比 | 逐步转向压铸、冲压、注塑和 MIM |
| 产线利用率 | 实际利用率跟上名义产能 |
| BOM 与售价 | 同时下降，毛利率没有坍塌 |

早期机器人依靠 CNC 方便修改设计。架构稳定后，整机厂会转向模具和自动化生产。这个变化比新建厂房更能证明量产成熟。

## 验证零部件公司的能力租金

| 要看什么 | 偏强信号 | 偏弱信号 |
|---|---|---|
| 客户阶段 | 正式量产定点 | 送样、测试、交流 |
| 收入 | 机器人业务收入持续增长 | 只披露订单或产能 |
| 现金 | 回款跟上收入 | 应收和库存快速增加 |
| 良率 | 扩产后仍能提高 | 依靠返工完成交付 |
| 寿命 | 有现场和实验寿命数据 | 只披露峰值参数 |
| 降价 | 降价后利润仍增长 | 份额增长但毛利率持续下降 |
| 客户结构 | 多家整机厂采用 | 依赖单一未量产客户 |

“进入头部客户供应链”不等于获得量产收入。

## 跟踪技术路线是否收敛

每半年更新一次：

- 每台旋转关节与线性执行器数量；
- 谐波、摆线、行星齿轮和直驱的比例；
- 丝杠采用滚珠还是滚柱；
- 双编码器是否成为标配；
- 腕部和足底力传感器的渗透率；
- 灵巧手自由度和主动驱动数量；
- 触觉传感器覆盖范围；
- 单机算力、功耗和电池容量；
- 整机厂关键模块的内制比例。

架构没有收敛前，不用单一路线推演百万台需求。

## 用阶段变化更新结论

### 仍处于小批量商业化

- 订单主要来自科研、展示和数据采集；
- 工厂只部署个位数或十几台；
- 人工接管频繁；
- 连续运行数据停留在几十或几百小时；
- 零部件公司收入主要来自样品。

### 确认进入产业加速

需要同时看到：

1. 多个客户从试点转为百台级付费采购；
2. 机器人能够连续运行数千小时；
3. 人工接管频率持续下降；
4. 客户复购和扩大部署；
5. 零部件量产收入、现金流和良率同步改善。

### 证伪近期放量

- 客户试点长期不转正式采购；
- 机器人只能在高度改造的环境中工作；
- 维护和人工接管成本超过节省的工资；
- 整机降价依赖供应商亏损；
- 产能利用率持续偏低；
- 技术路线频繁变化，已建产能需要重新投资。

## 当前基线

| 项目 | 2026 年 7 月判断 |
|---|---|
| 整机制造 | 已进入小批量商业化 |
| 运动能力 | 快速进步 |
| 灵巧操作 | 仍是主要瓶颈 |
| 工业可靠性 | 数据不足 |
| 机器人小时经济性 | 尚未普遍成立 |
| 零部件订单 | 开始增长，量产与样品混杂 |
| 技术路线 | 尚未收敛 |
| 投资阶段 | 预期领先于利润兑现 |
