# 判断零部件价值落在哪里

> 当前结论：执行器是最大的硬件价值块。真正能留下能力租金的不是单一零件参数，而是精密工艺、量产良率、寿命数据、自动标定和跨客户交付能力。

## 不用一张固定 BOM 推演未来

人形机器人还没有统一架构。

- 宇树 G1 使用旋转电机和两级行星减速器。
- 部分重载机器人采用线性执行器和行星滚柱丝杠。
- 灵巧手正在尝试微型电机、腱绳、丝杠和直驱方案。
- 力控可以使用六维力传感器，也可以通过关节电流估算。

技术路线不同，单机需要的减速器、丝杠、轴承和传感器数量会完全不同。

所有“单机价值量乘以百万台”的测算，都要先说明采用了哪一种架构。

## 先看大致价值结构

以下区间用于理解价值分布，不是行业统一 BOM。

| 环节 | BOM 占比参考 |
|---|---:|
| 执行器及内部零件 | 35%—50% |
| 灵巧手与触觉 | 10%—20% |
| 视觉、力觉和其他感知 | 8%—15% |
| 控制器与芯片 | 10%—18% |
| 电池 | 3%—6% |
| 结构件及其他 | 15%—25% |

执行器价值量最高，因为一台机器人通常需要 20—50 个运动自由度。每个关节又包含电机、传动、编码器、驱动、轴承、结构和热管理。

价值量高不代表外部供应商一定能获得利润。整机厂越重视这个模块，越可能参与设计或直接内制。

## 逐个判断零部件

| 环节 | 真正的技术壁垒 | 内制风险 | 价格战风险 | 当前判断 |
|---|---|---:|---:|---|
| 一体化关节执行器 | 扭矩密度、回差、散热、寿命、控制匹配 | 高 | 中高 | 高价值，竞争最激烈 |
| 谐波减速器 | 柔轮材料、齿形、热处理、疲劳寿命 | 中 | 高 | 有增量，不等于有高利润 |
| RV/摆线减速器 | 精密加工、抗冲击和寿命 | 低 | 中高 | 适合重载，体积限制人形应用 |
| 无框力矩电机 | 电磁设计、槽满率、转矩波动、热路径 | 高 | 高 | 容易扩产，必须看量产一致性 |
| 行星滚柱丝杠 | 滚道几何、磨削、预紧、效率和寿命 | 中 | 中高 | 壁垒较高，路线风险也高 |
| 精密轴承 | 薄壁、高刚性、预紧、热处理和寿命 | 低 | 高 | 跨架构需求稳定，单件价值有限 |
| 编码器 | 绝对精度、温漂、时延、抗污染 | 中 | 中 | 高端产品有租金，低端快速降价 |
| 六维力传感器 | 解耦、温漂、过载、长期标定 | 中高 | 中 | 工业作业重要，可能被算法部分替代 |
| 触觉传感器 | 耐磨、漂移、剪切力、布线和标定 | 高 | 低 | 空间大，技术路线最不确定 |
| 灵巧手 | 机构、驱动、触觉、控制和耐久协同 | 高 | 中 | 能否稳定干活的核心瓶颈 |
| 视觉硬件 | 低时延、遮挡处理和多传感融合 | 中 | 高 | 硬件容易标准化，价值向软件转移 |
| 控制器与芯片 | 实时性、功耗、工具链、功能安全 | 中 | 中 | 平台价值高，国内可投资映射较弱 |
| 电池 | 峰值功率、安全、热管理和快速换电 | 高 | 高 | 电芯较通用，电池包由整机厂主导 |
| 结构件 | 轻量、刚度、碰撞安全、可维修性 | 高 | 很高 | 放量明显，租金较低 |

## 找到可能收能力租金的环节

### 精密工艺和可靠性

滚柱丝杠、薄壁轴承、高精度编码器和力传感器都需要精密制造。样品做出来不难，难的是把数十万件产品的精度、寿命和良率保持一致。

值得跟踪的能力包括：

- 自有磨削和热处理；
- 专用加工设备；
- 自动测量与标定；
- 万小时寿命数据；
- 降价后的稳定良率；
- 多家整机客户。

### 灵巧手、触觉和力控

当前机器人已经能走，仍不擅长稳定操作物体。

灵巧手的壁垒不在传感片或微型电机本身。机械结构、触觉、控制算法和任务数据要形成闭环。任何一个环节不稳定，整只手都不能工作。

这条路线空间最大，技术和商业风险也最高。

### 测试、标定和生产设备

机器人进入量产后，每个关节、传感器和整机都需要测试与校准。

这类设备可以同时服务多家整机厂，也不依赖某一种关节架构。市场规模可能小于核心部件，但客户切换成本和毛利结构可能更好。

## 警惕整机厂收回关键模块

Figure 已经把执行器、手、电池、传感器、结构和电子系统的大量设计与核心装配放在内部。宇树也销售自研关节电机和控制系统。

外部供应商要回答一个问题：

> 整机厂为什么不自己做？

合理答案包括：

- 需要整机厂没有的专用设备；
- 材料和热处理经验难以复制；
- 外部供应商拥有更高良率；
- 多客户规模能够持续降低成本；
- 更换供应商需要重新完成寿命和安全验证。

如果答案只是“现在供不应求”，这更接近身位红利。

## 识别容易变成价格战的环节

下面这些方向会受益于整机放量，但很难长期保持高利润：

- 普通磁材、铜线和结构加工；
- 通用电芯和电池材料；
- 没有自有工艺的无框电机组装；
- 依靠扩产形成的普通减速器和轴承产能；
- 标准视觉传感器；
- 只有送样、没有量产收入的概念供应商。

国产替代经常同时带来份额增长和价格下降。销量上升不能直接推出利润率上升。

## 用六个问题筛选公司

1. 这颗零件是否一定会出现在最终架构里？
2. 整机厂为什么不自己做？
3. 客户更换供应商需要付出什么成本？
4. 从一千件做到一百万件时，良率和寿命能否保持？
5. 年降价 10%—20% 后还能不能赚钱？
6. 当前收入来自量产，还是样品和资本市场预期？

能回答这六个问题，才有可能获得能力租金。
