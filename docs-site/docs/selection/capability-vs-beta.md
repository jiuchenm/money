# 先问它赚的是哪种钱：能力租金还是身位红利

浪潮框架回答"何时上车"。这一篇回答"上哪辆车"。这是两个不相干的问题。

同一波浪潮里，选对标的和选错标的，收益天差地别。江波龙 vs 海力士就是活证据。

---

## 只问一个问题

面对任何一只在浪潮里涨起来的股票，只问一句：

> 它赚的钱，是能力租金，还是身位红利？

| | 能力租金 | 身位红利 |
|---|---|---|
| 钱从哪来 | 核心技术、专利、产能壁垒 | 囤货、蹭概念、单纯的贝塔敞口 |
| 为什么归你 | 别人做不到，钱只能流向你 | 别人也能做，你只是正好站在风口 |
| 浪潮退去后 | 壁垒还在，还能继续收租 | 打回原形，甚至被高价库存反噬 |
| 利润性质 | 可持续的定价权 | 一次性的价差、存货重估收益 |
| 财务特征 | 毛利率高且稳，持续投研发 | 毛利率随行情大起大落，研发占比低 |
| 存储业里谁是谁 | 海力士、三星、美光（原厂 IDM，做 HBM 工艺） | 模组厂（靠囤颗粒赚库存收益） |

---

## 利润为什么往壁垒那一环沉淀

产业链是一条河。利润会往壁垒最高的那一环沉淀。

存储产业链是这样分层的：

```
晶圆/颗粒原厂(IDM)  →  模组厂  →  分销/品牌
[三星/海力士/美光]    [组装封装]   [渠道]
   ↑ 技术壁垒极高      ↑ 壁垒低      ↑ 壁垒低
   ↑ 定价权在这        ↑ 赚加工/价差 ↑ 赚周转
```

原厂掌握晶圆制造工艺。HBM 这种环节良率极低、技术代差明显，资本开支门槛数百亿美元，是寡头格局。浪潮涨价的利润，主要归它们。📗（SK 海力士 2025 EBIT 达 362.5 亿美元，营收 687 亿；全球首发 12 层 HBM3E 供货英伟达，Q2 2025 占 DRAM 市场 38%。它是自建晶圆厂的 IDM。）

模组厂向原厂采购颗粒，做组装、测试、品牌，不掌握颗粒制造。行情好时靠低价囤货、涨价卖出赚库存收益，业绩爆发。行情反转时，高价库存反成负担，业绩坐过山车。

**你要买的是壁垒本身，不是壁垒的搬运工。**

---

## 三个切口，快速判断是哪一类

### 切口 1：看毛利率高不高、稳不稳

能力租金的毛利率高，而且相对稳定。壁垒撑住了定价权。

身位红利的毛利率随行情大起大落。它没有定价权，只是价差的传导者。

看到某公司毛利率突然从个位数飙到很高，要警惕。这往往是库存重估收益，不是能力变强了。

### 切口 2：追问业绩爆发靠什么

问一句：如果原材料价格不涨，这家公司还赚这么多吗？

能力租金的答案是"是"。它靠工艺、份额、产品力。

身位红利的答案是"否"。它的业绩等于囤货乘以涨价，是一次性的。

江波龙就是这种陷阱。它业绩爆发的来源是囤了便宜颗粒、颗粒又涨价，不是掌握了核心生产技术。涨价周期一结束，库存收益就消失。

### 切口 3：看研发投入和技术代差

能力租金持续高研发，有明确的技术领先，比如 HBM 领先一代。

身位红利研发占比低，技术上跟随或只做组装，没有代差优势。

---

## 一句话决策

```
浪潮来了 → 这家公司在浪潮中赚的是能力租金还是身位红利？
  → 能力租金（壁垒/份额/工艺） = 候选
  → 身位红利（囤货/蹭概念/贝塔） = 回避,哪怕它现在涨得最猛
```

身位红利股往往在浪潮狂热期涨得最猛。它弹性大、故事性强，所以最诱人。用这个判据把它们筛掉。

## 和浪潮框架怎么配合

| 问题 | 去哪一模块 | 它回答什么 |
|---|---|---|
| 何时 | framework 篇 | 浪潮在哪个阶段？何时进出？ |
| 选谁 | 本篇 | 买能力租金，不买身位红利 |

两个都对，才赚大钱：对的浪潮，加对的阶段，加能力租金标的。

缺一样就会亏。对了浪潮却买错标的（江波龙），或者选对标的却在错的阶段介入（狂热期买海力士），都吃不到肉。
