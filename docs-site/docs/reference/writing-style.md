# 写作风格约定

这份 KB 是给你自己看的决策工具，不是给别人看的表演。写作只有一个目的：让你在做投资决策时，快速读懂、用得上。

下面的规矩，新写的每一篇都要守，旧的逐步改过来。参考了 Mozilla 知识库写作指南和 MDN 的"三 C 原则"（clear, concise, consistent）。

## 六条硬规矩

**1. 一句话只说一件事。** 长句拆短。不要用破折号把三层意思塞进一句。

**2. 用主动语态，直接说"你"。** 不写"这个组合意味着风险"，写"你这样做会亏钱"。

**3. 砍词。** 删掉"其实""恰恰""某种程度上""值得一提的是"这类词。它们不承载信息，只拖慢阅读。

**4. 少加粗。** 加粗只留给真正的关键判断，一段最多一处。满屏加粗等于没有重点。

**5. 标题带动词、说具体事。** 写"如何判断浪潮见顶"，不写"浪潮衰竭期特征"。

**6. 结论先行。** 先给答案，再讲理由。不要为了铺垫"顿悟感"把结论藏到最后。

## 要避免的语气

- **不要制造戏剧感。** 不写"这恰恰是最危险的诱惑""这是整个系统最值钱的部分"。事情该怎样就说怎样。
- **不要自我总结升华。** 每段结尾不需要一句拔高的话。
- **不要堆比喻。** "雷达站""透镜"这类比喻，全篇用一两次就够，不要反复敲。

## 一个对照例子

改前（AI 味重）：

> 你把"20% 收益 + 一个宏大叙事"放在一起，这个组合本身就是我们框架里最需要警惕的模式——叙事最动人的时候，往往是情绪最贵的时候。

改后：

> 你手里有两样东西：20% 的浮盈，和一个动人的故事。这两样凑在一起最容易让人犯错。故事讲得越好，你越舍不得止盈。

改后更短、更直接、没有拔高，但意思没丢。
