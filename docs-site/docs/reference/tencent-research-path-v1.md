# 复用腾讯消息、技术与宏观研究路径

记录日期：2026-09-22。这是本次实际执行总结，不是Skill，也不改Tide核心原则。

## 先固定信息集，再并行取证

每次明确报告日期、港股交易时段、价格截点和新闻截点。盘前、收盘后不能混用；盘后新消息只能影响未来判断。至少保存发生日期、公布日期、精确可得时间、抓取时间。来源只给日期时，精确时间保留空值。

调研分三条线：AI模型/Agent/算力工具；腾讯与中国互联网/政策；全球科技硬件/财报/供应链及宏观。每条先查近7天，证据不足扩至30天。三组并行只负责取证，不按各组结论投票。

本次原始候选36+44+35=115项；跨组去重、删除例行小版本与弱相关条目后保留105项，其中101科技、4宏观，69核验、36部分核验。没有全网热搜统计，因此不能说这是排名前100。后续若要求客观热度，需另取统一口径的搜索/阅读/讨论数据和时间窗。

## 让一条话题对应一个事件

每条保存id、标题、类别、源URL、来源名称、发生日、发布时间、available_at、原始证据定位、自写摘要、热度依据、与腾讯的传导、证据等级与局限。

同一公司发布的功能列表合并；转载和原文合并；同一事件隔日复盘不算新事件。不同产品/不同日期的独立发布可保留，但要标注同一大会背景。公司声称的产品性能、计划采购与真实收入分开。

用官方文章、发布日志、GitHub release与IR核验存在及日期。媒体报道用于确认市场关注、竞争关系和价格反应。浏览器标题/搜索摘要不能承担全部事实；只核到摘要时标partial。不能因部分源失败声称当天没有重大消息。

新闻进入结论前走一次事件 → 用户/客户 → 收入/成本 → 利润/现金流 → 估值传导。背景话题可以保留，不必硬连到腾讯。按因果链合并相关指标，不数利好票数。

## 先检查行情，再计算指标

原始来源只存私有目录。每条行情有来源、币种、单位、抓取时间和调整口径。双源核对日期、收盘与量额；发现冲突再取第三源。第三源一致只是供应商裁决，不能等同交易所认证。

本次Yahoo与Eastmoney近三年均覆盖737条。四个半日收盘冲突经Tencent行情交叉核对。2016年以来虽可拉取2640条Yahoo记录，但2023年前存在价格调整口径差异，因此只使用2023-01-05起911条可比样本。

HKEX交易日历也须处理特殊休市，不能只用工作日。9月1日和8日2023年无K线经官方全天停市公告确认。缺最后交易日、末条未完成或存在未裁决冲突时，不生成新日期报告。

从统一日线聚合周/月OHLC和量额，当前周/月标partial。未复权价用于实际价位图；因果现金分红处理用于模型动量，跨除息标签排除。不能混合复权收盘与原始高低价。不得用close×volume假充成交额。

## 让全球数据服从可得时间

美股取当时已经完成的时段。外汇/商品使用保守可得时间；休市与缺数须分别标记。FRED修订版本未准备好时，不把今天看到的修订数据喂给历史回测。

本次FRED两次超时后停止重试，改用Fed、HKMA、HKAB官方当前信息，并明确完整收益率与信用利差序列缺失。HKMA月度统计API只到8月末，不能当9月22日HIBOR；HKAB页面只显示9月21日，也如实写日期。

## 把分析、算法和交易分开验证

每日判断的骨架是消息、技术、宏观。算法只使用有历史可得性的数据。第一版没有历史新闻训练集，所以新闻仅用于当前解释与情景，不伪称50个数值state包含新闻。

目标分别为终点收益、相对起点最大上冲、最大下探、收盘路径最大回撤。First-hit先检查跳空开盘，若日内同时触障碍才记顺序未知。收益窗口未成熟不计分。

本次固定小型LightGBM配置，按时间切分、留校准集、清除标签窗口重叠；与成熟历史标签经验分位数比较。原分位数用Pinball loss，校准区间用覆盖与宽度。原分位数和conformal扩展边界必须分开存。

本次全部12个目标未胜基线，模型没有晋升。情景价格只作观察，ATR扩展范围明确写推导，不伪造条件胜率。下一次增加正式预注册、波动基线、区块不确定性和更长前瞻记录，不能仅为好看反复调参。

## 保存可复查产物

程序入口在仓库的 `nikki/research/tencent`，包含采集、分析、组装、只监听loopback的本地服务和标签回归测试。研究原始文件、特征、回测与新闻证据存于被Git忽略的research-private。完整网页数据不复制进公开static目录。

每次组装生成prediction_id，保存当时快照。公开发布前独立核对数据展示权限和个人信息，不把开源代码许可误认为行情数据许可。新闻摘要自己写，保留原链接，不复制新闻全文。

首版验收覆盖构建、日期/标签/除息测试、浏览器日周月切换、搜索筛选、页面错误日志和实际快照读回。后续已接每日19:10的本地Codex调度与同一Nikki Pages部署：公开原创研判、话题摘要及模型评价，完整行情仍保留本地。电脑与Codex需要运行。尚未创建Skill；相关路径可作为后续Skill设计的实际依据。
