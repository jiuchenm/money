# 权威数据源清单

> 按浪潮驱动力类型组织。定期分析时从这里取数，不凭记忆。

---

## 货币 / 信用周期型（黄金、美元、利率）

| 指标 | 数据源 | 说明 |
|---|---|---|
| 黄金需求/央行购金 | World Gold Council (gold.org/goldhub) | 季度 Gold Demand Trends 报告 |
| 黄金基准价 | LBMA | 伦敦金定盘价 |
| 实际利率 | FRED (fred.stlouisfed.org) | 10年期TIPS收益率，黄金的核心对手盘 |
| 美元指数 DXY | ICE / TradingView | 美元强弱 |
| 美元储备份额 | IMF COFER | 去美元化的量化证据 |
| 美联储政策 | Federal Reserve | FOMC 声明、点阵图 |

## 技术 / 产业链型（存储、半导体、AI）

| 指标 | 数据源 | 说明 |
|---|---|---|
| DRAM/NAND 合约价 | TrendForce, DRAMeXchange | 逐季合约价，最直接的存储浪潮温度计 |
| HBM 供需 | TrendForce | AI 拉动的高带宽内存 |
| 存储厂财报 | Micron, SK Hynix, Samsung | 资本开支、库存、指引 |
| 半导体产业动态 | DigiTimes, SemiAnalysis | 产业链一手信息 |

## 地缘 / 冲击型（原油、大宗商品）

| 指标 | 数据源 | 说明 |
|---|---|---|
| Brent / WTI 原油 | ICE / CME | 实时期货价 |
| 原油供给/库存 | EIA (eia.gov) | 美国能源署，供给端权威 |
| 地缘事件 | Reuters, Bloomberg, FT | 一手时间线 |
| 霍尔木兹海峡 | EIA / 航运数据 | 全球约 20% 原油经此，关键咽喉 |

## 通用宏观

| 指标 | 数据源 | 说明 |
|---|---|---|
| PMI | 各国统计局 / Markit | 景气领先指标 |
| 全球流动性 | 各主要央行资产负债表 | 浪潮的水位 |
| 综合宏观数据 | FRED (fred.stlouisfed.org) | 最全的免费宏观数据库 |

---

## 使用原则

1. **先行指标优先**：宁可盯合约价、实际利率这类领先量，不盯已经反映在价格里的滞后量。
2. **交叉验证**：一个判断至少两个独立源支撑。
3. **记录读数**：每期分析把读数抄进浪潮档案的"信号仪表盘"，形成时间序列。
