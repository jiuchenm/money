# 一波浪潮怎么走完四个阶段

一波浪潮不是一条直线。它分四个阶段，每个阶段都有能观测到的特征。

你两个最痛的问题——进得太早太晚，和拿到衰竭还不走——根子都在一件事上：你没认清自己站在哪个阶段。这个模型就是帮你把"感觉"换成"看得见的证据"。

---

## 模型总览

```
估值    │                                   ╱╲  ← 狂热(散户接盘)
        │                              ╱╲ ╱   ╲
        │                        ╱────╱  V      ╲
        │                   ╱───╱   加速(机构进场) ╲
        │              ╱───╱                        ╲╲  ← 衰竭
        │      ________╱  萌芽(估值荒漠)              ╲╲____
        └────────────────────────────────────────────────── 时间
          ①萌芽期        ②加速期        ③狂热期      ④衰竭期
```

钱是从②赚到③的。①太早，你会煎熬，而且可能证明你看错了。④太晚，你在接盘。所以你要练的只有两件事：认出①转②的那一刻（进场），认出③转④的那一刻（离场）。

---

## ① 萌芽期：便宜，没人要

底层的驱动已经出现了，但市场还没认。价格便宜，没人问津。

怎么认出来：
- 主流媒体忽视它，甚至嘲笑它。
- 估值在历史低位。行业刚出清过一轮，产能和资本开支都被砍了。
- 只有产业里的人和少数逆向投资者在看。
- 先行指标已经悄悄转向，但价格还没动。这条最关键。

存储就是例子。2023 年存储下行周期，厂商大砍资本开支。这正是 2025-26 涨价的种子——供给要收紧了。当时没人看好，典型的萌芽期。

这个阶段你只做逆向布局。风险是便宜可以更便宜，而且可能被证伪。所以只用小仓位试探，核心是先确认底层驱动是不是真的（见档案模板"底层驱动"栏）。

你"盲目抄底"的教训大多发生在这里。抄底不等于萌芽期布局。区别只有一条：布局有先行指标转向的证据，抄底只有"跌得够多了"的情绪。

---

## ② 加速期：机构进场，主升浪

驱动逻辑被越来越多专业资金认可，趋势确立，价格稳步往上抬。这是主升浪，是你赚钱的主战场。

怎么认出来：
- 卖方研报开始覆盖，机构调仓进来。
- 价格创阶段新高，但估值还合理，盈利和基本面同步在改善。
- 先行指标持续向好并被验证：合约价连涨、库存去化、需求数据超预期。
- 每次回调都有支撑，都被买回去。

黄金是例子。2024-2025 黄金进入加速期：央行持续购金、ETF 资金流入、连续刷新高，背后有实际利率、去美元化这些能验证的支撑，不是纯情绪。

存储也是例子。2025-2026 合约价逐季上涨（Server DRAM +13~18%、SLC NAND +120~170%），AI 服务器需求被验证，加速期特征齐全。

这是"伴随持有"的核心区间。你建主仓，忍受正常回调，跟着趋势走。持续跟踪先行指标，只要驱动逻辑没破、指标没转向，就拿住。

这一阶段最考验你。A股经验让你习惯"落袋为安"，可在真浪潮的加速期过早卖出，正是你"多年未赚钱"的一个典型原因。

---

## ③ 狂热期：散户接盘

主题进了大众视野，散户蜂拥而入。价格脱离基本面，靠情绪和叙事在涨。

怎么认出来：
- 主流媒体、社交平台铺天盖地。出租车司机、亲友都在谈。
- 估值创历史极值，跟基本面背离，价格涨速远超盈利。
- 新玩家疯狂进入：厂商大举扩产、新基金成立、IPO 潮。
- "这次不一样"的叙事盛行，看空的人被嘲笑。
- 先行指标开始钝化或见顶，价格却还在涨。背离出现了。

这里是分批兑现的区间，不是加仓的区间。此阶段最贵的情绪是贪婪。别想着"再拿一会儿"，④的转折常常来得猝不及防。技术产业链型浪潮里，厂商疯狂扩产就是衰竭前兆——未来产能过剩就是这么来的。

---

## ④ 衰竭期：反转

驱动力耗尽或者反转。货币周期见顶、产能过剩释放、需求被证伪。价格崩塌。

怎么认出来：
- 先行指标明确反转：合约价转跌、库存累积、央行停止购金、实际利率大幅上行。
- 利好出尽，价格对好消息不再反应，对坏消息剧烈反应。
- 前期扩的产能开始释放，供给过剩。
- 叙事破裂，资金夺路而逃。

地缘冲击型的衰竭极快。美伊冲突停火后，避险溢价当日蒸发，金价 -2%。这类浪潮的④紧跟在①之后，几乎没有中间阶段。

这个阶段就是清仓，不恋战。你"长期持有到衰竭"的痛点，就是没在这里离场。退出信号见 [时点决策](./entry-timing) 和各浪潮档案的"退出信号"栏。也别抄底，衰竭后的下跌往往很漫长，等下一轮萌芽期再说。

---

## 三类驱动力的阶段节奏不一样

不同驱动力，四阶段的时长比例完全不同（见 [浪潮分类学](./taxonomy)）：

| 驱动力 | ①萌芽 | ②加速 | ③狂热 | ④衰竭 |
|---|---|---|---|---|
| 地缘冲击型 | 几乎无 | 数天 | 数天 | **瞬间**（事件平息） |
| 货币/信用周期型 | 数年 | **数年**（最长主升浪） | 数月 | 缓慢数年 |
| 技术/产业链型 | 1-2年 | **数季度~2年** | 数季度 | 数季度（产能释放） |

货币型和技术型的②加速期最长最肥，是"伴随持有"的主战场。地缘型没有可以持有的加速期。

---

## 怎么判断我现在站在哪个阶段

问自己四个问题：

1. 媒体热度：无人问津(①) → 机构覆盖(②) → 全民热议(③) → 叙事破裂(④)。
2. 估值 vs 基本面：便宜(①) → 同步(②) → 背离(③) → 崩塌(④)。
3. 先行指标 vs 价格：指标先动价格未动(①) → 指标价格齐涨(②) → 指标钝化价格仍涨(③) → 指标反转价格跟跌(④)。
4. 供给端反应：出清(①) → 温和(②) → 疯狂扩产(③) → 产能过剩(④)。

最有用的是第 3 条：先行指标和价格的背离。①是"指标领先价格"的正向背离，是买点。③④是"价格脱离指标"的负向背离，是卖点。
