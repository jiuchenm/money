# 什么时候进、什么时候出

你最痛的两点：进得不是时候，和拿到衰竭还不走。这个文件就是解药。它把"何时进、何时出"变成可执行的判据，不靠感觉。

---

## 你介入的不是价格，是阶段加证据

A股经验让人习惯盯价格：涨了追，跌了抄。浪潮投资盯的是阶段切换的证据。
- 买点是①萌芽末转②加速初：先行指标转向，被价格确认。
- 卖点是③狂热转④衰竭：先行指标反转，价格背离。

永远不在③狂热期开新仓。永远不在④衰竭期还抱着不放。

---

## 介入决策矩阵

介入前四项全过，缺一项就不进：

| 检查项 | 通过标准 | 不通过就不进 |
|---|---|---|
| 1. 驱动力归类 | 明确是货币型或技术型（可持有），不是纯地缘冲击型 | 是冲击型就不做趋势，只识别回避 |
| 2. 底层驱动真实 | 能一句话说清本质的供需或货币变化，经得起证伪 | 说不清就是噪音，不进 |
| 3. 阶段定位 | 在①末或②，不在③④ | 在③④就不追，等下一轮 |
| 4. 先行指标转向 | 至少一个核心先行指标已确认向好 | 只有"跌多了"的情绪就是盲目抄底，不进 |

第 4 项是分水岭，它区分"萌芽期布局"和"盲目抄底"。**抄底看价格，布局看指标。**

---

## 仓位跟着阶段递进，不是一次满仓

| 阶段 | 仓位动作 | 为什么 |
|---|---|---|
| ①萌芽 | 小仓试探（10-20%） | 可能证伪，用小仓换确认 |
| ②加速初 | 加至主仓（50-70%） | 趋势确立，先行指标验证 |
| ②加速中 | 持有，回调可补 | 主升浪，拿住 |
| ③狂热 | 停止加仓，开始分批减 | 情绪驱动，风险累积 |
| ④衰竭 | 清仓 | 驱动反转，不恋战 |

---

## 退出决策矩阵

这一节对治"持有到衰竭"。以下信号只要同时出现任意两条，就启动退出：

| 退出信号 | 怎么看 |
|---|---|
| 先行指标反转 | 合约价转跌 / 央行停购 / 实际利率大幅上行 / 库存累积 |
| 价格与指标背离 | 指标钝化或下行，价格仍在涨（负向背离） |
| 供给端过热 | 厂商疯狂扩产、大量新玩家进入、IPO潮 |
| 叙事到达大众 | 出租车司机、亲友都在谈，媒体全面追捧 |
| 利好出尽不涨 | 出重大利好但价格没反应，甚至下跌 |
| 估值历史极值 | 估值创历史新高且与基本面背离 |

每个浪潮的具体退出信号，你要事先写在浪潮档案里（见 `20-waves/_template.md` 第五栏）。事前写好，是为了防止事到临头被"再拿一会儿"的贪婪劫持。

---

## 时点纪律：写死，不临场议价

1. 不在狂热期开新仓。哪怕它还在涨。错过不等于亏损。
2. 退出信号触发就执行。不找"这次不一样"的理由。
3. 地缘冲击不追高。冲击顶点常常是卖点。
4. 分批，不赌单点。建仓分批，退出分批，降低对择时精度的要求。
5. 证伪条件写在前面。介入时就写好"什么情况证明我错了"，触发就认错离场。

---

## 一句话决策流程

```
这是哪类浪潮？ → 能持有吗？ → 在哪个阶段？ → 先行指标怎么读？
   → ①末②初且指标转向 = 建仓
   → ②中且指标未反转 = 持有
   → ③④或指标反转 = 减/清
```
