# 潮 Tide

> 潮有涨落，be water——看清周期在哪一段，该进则进，该退则退。

一套开源的投资知识库和方法论。写给中国散户：帮你少走弯路，把价值投资真正落到能操作的地步，避开常见的坑。

## 为什么做这个

中国的投资市场还很初级，散户多，容易被情绪和故事带着走。市面上"风口""浪潮""财富自由"的话术满天飞，挖坑的人正是喊这些口号的人。

这套东西反着来。它不给你荐股，不许诺暴富。它教你三件事：

1. **看清一个机会是哪一类，现在处在周期的哪一段**，再决定动作。反冲动。
2. **分清事实和故事**，查证过才敢下注。反情绪、反炒作。
3. **买有壁垒的公司，不买蹭概念的**。反割韭菜。

名字叫「潮」，因为潮水涨完必退。大多数人只惦记涨，忘了退。李小龙讲 be water，说的也是顺着周期的形状走，不预设、不执念。

## 里面有什么

- **周期识别方法论**：把机会分成三类（地缘冲击型、货币信用周期型、技术产业链型），讲清每一类涨多久、能不能长期拿。再讲一个机会从萌芽到衰竭的四个阶段，以及每个阶段该做什么。
- **选股方法**：同一个方向里，怎么区分有壁垒的公司和蹭概念的公司。用真实案例（海力士 vs 江波龙）讲透。
- **反模式清单**：盲目抄底、持有到衰竭、过早落袋这些坑，逐个拆解怎么破。
- **定期分析日志**：把方法论用在当下的真实机会上，写下判断，事后复盘对错。

## 怎么看

内容是一个 [Docusaurus](https://docusaurus.io/) 站点。

```bash
cd docs-site
npm install     # 首次运行，装依赖
npm start       # 本地预览，打开 http://localhost:3000
```

## 一句话免责

这里没有任何荐股，也不构成投资建议。它是一套帮你自己做判断的方法。市场有风险，钱是你自己的。
